# Grimhold — страница статуса

Публичная страница о том, что уже работает в игре Grimhold: ролик из игры
с главами, кадры механик, журнал обновлений и кнопка отзыва.

**Кода игры здесь нет и не будет** — только эта страница, кадры, ролик
и шрифты. Сама игра живёт в закрытом репозитории.

- `index.html`, `style.css`, `site.js` — страница; русский и английский.
- `feedback.js` — отзыв: страница открывает соединение с сервером игры
  (`wss://grimhold-online.lumihub.dev/ws`), решает его задачу «докажи
  работу» и шлёт тикет — тот же, что из самой игры. Разработчик видит его
  в меню игры, во вкладке «Тикеты».
- `media/grimhold.mp4` — ролик из игры (1600×900, H.264), `media/poster.webp` — обложка.
- `shots/*.webp` — кадры механик.
- `fonts/` — EB Garamond и Cormorant SC, лицензия SIL OFL рядом.

Страница открывается по адресу <https://wprotvbanke.github.io/Grimhold-site/>
(GitHub Pages, ветка `main`, корень).
